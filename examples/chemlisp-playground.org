#+title: Experimental CheMLisp playground
#+author: Giovanni Crisalfi
#+STARTUP: inlineimages
#+OPTIONS: toc:2

A scratch buffer for trying the experimental CheMLisp DSL.  CheMLisp's syntax,
public API, and rendered output may change without notice.

Evaluate the *Setup* block once with =C-c C-c=, then put point in any other
block and press =C-c C-c= to render it.  Toggle image preview with
=C-c C-x C-v=, or run =M-x chem-org-regenerate-buffer= to refresh every block.

CheMLisp uses Indigo for automatic 2D layout and hydrogen perception, so the
Indigo module is required.  Explicit geometry is an override, not a
prerequisite: omit angles for the default depiction, and add them only when
you want to force a particular arrangement.

CheMLisp blocks are fontified with `lisp-data-mode`; `C-c '` opens them in that
mode.

* Setup

#+begin_src elisp :exports none :results silent
(require 'chem-babel)
(setq org-confirm-babel-evaluate nil)
#+end_src

* Basics

** Ethanol

No angles: Indigo computes the chain layout.

#+begin_src chemlisp :results file
(molecule
  (C
    (C
      (O))))
#+end_src

** Acetic acid

#+begin_src chemlisp :results file
(molecule
  (C
    (C
      (=O)
      (O))))
#+end_src

** Branches

The first atom child continues the main chain; the others are branches.

#+begin_src chemlisp :results file
(molecule
  (C
    (C
      (C)
      (O))
    (C)))
#+end_src

** Forcing angles

Explicit =:angle=, =:turn=, and =:length= override the automatic layout on
acyclic bonds and ring substituents.  Explicit geometry on ring-internal bonds
is rejected; use the molecule view to orient a whole ring.

#+begin_src chemlisp :results file
(molecule
  (C
    (C :angle 90
      (O :angle 30)
      (C :angle -30))))
#+end_src

** Charges and hydrogens

~:charge~ and ~:h~ are atom attributes.  ~:h~ is encoded with explicit
hydrogens, so impossible values are rejected.

#+begin_src chemlisp :results file
(molecule
  (N :charge 1 :h 4)
  (O :charge -1))
#+end_src

* Rings

Indigo computes ring coordinates.  Lowercase atoms are aromatic and rings are
laid out automatically; no angles are needed.

** Benzene

#+begin_src chemlisp :results file
(molecule
  (c
    (c
      (c
        (c
          (c
            (c
              (-> ^5))))))))
#+end_src

** Naphthalene

Fused rings use one tree.  The second ring branches from the shared atom `b`
and closes back to `a`; no IDs are needed.

#+begin_src chemlisp :results file
(molecule
  (c
    (c
      (c (c (c (c (-> ^5)))))
      (c (c (c (c (-> ^5))))))))
#+end_src

The shared atoms can be named when that is clearer:

#+begin_src chemlisp :results file
(molecule
  (c :id a
    (c :id b
      (c (c (c (c (-> a)))))
      (c (c (c (c (-> a))))))))
#+end_src

* Stereochemistry

A ~>~ prefix (for example ~>Br~) is an up wedge and ~<~ is a down wedge.
The explicit angles here force the branch directions around the center.

#+begin_src chemlisp :results file
(molecule
  (C
    (C :angle 30
      (N :angle 60)
      (>Br :angle -60)
      (O :angle 180))))
#+end_src

* Definitions

** A value definition

#+begin_src chemlisp :results file
(chem-def hydroxyl ()
  (O))

(chem-def methyl ()
  (C))

(molecule
  (C
    (C (hydroxyl))
    (methyl)))
#+end_src

** A template

~para~, ~meta~, and ~ortho~ are holes.  Missing arguments default to
~nil~ and remove the hole.

#+begin_src chemlisp :results file
(chem-def phenyl (ortho meta para)
  (c
    (c
      (c
        (c
          (c
            (c
              (-> ^5)))
          (para))
        (meta))
      (ortho))))

(molecule
  (phenyl :ortho (O)))
#+end_src

** Two substituents

#+begin_src chemlisp :results file
(chem-def phenyl (ortho meta para)
