#+title: Experimental CheMLisp playground
#+author: Giovanni Crisalfi
#+STARTUP: inlineimages
#+OPTIONS: toc:2

A scratch buffer for trying the experimental CheMLisp DSL.  Evaluate the *Setup* block once with
=C-c C-c=, then put point in any other block and press =C-c C-c= to render it.
Toggle image preview with =C-c C-x C-v=, or run
=M-x chem-org-regenerate-buffer= to refresh every block.

CheMLisp blocks use the pure-Elisp compiler and SVG exporter; they do not need
the Indigo module.  Only SMILES/MOL/RXN blocks load Indigo on demand.

* Setup

#+begin_src elisp :exports none :results silent
(require 'chem-babel)
(setq org-confirm-babel-evaluate nil)
#+end_src

** Branches

The first atom child continues the main chain; the others are branches.

** Charges and hydrogens

~:charge~ and ~:h~ are atom attributes.  ~:h~ is only needed when the
default valence is not what you want.

#+begin_src chemlisp :results file
(molecule
  (N :charge 1 :h 4)
  (O :charge -1))

* Rings

** Benzene

Lowercase atoms are aromatic.  Ring bonds need explicit angles to close.

#+begin_src chemlisp :results file
(molecule
  (c :id c1
    (c :id c2 :angle 0
      (c :id c3 :angle 60
        (c :id c4 :angle 120
          (c :id c5 :angle 180
            (c :id c6 :angle 240
              (close c1))))))))
#+end_src

* Stereochemistry

~>C~ is an up wedge and ~<C~ is a down wedge.

  (C

** A template

~para~, ~meta~, and ~ortho~ are holes.  Missing arguments default to
~nil~ and remove the hole.

#+begin_src chemlisp :results file
(chem-def phenyl (ortho meta para)
  (c :id c1
    (c :id c2 :angle 0
      (c :id c3 :angle 60
        (c :id c4 :angle 120
          (c :id c5 :angle 180
            (c :id c6 :angle 240
              (close c1)))
          (para))
        (meta))
      (ortho))))

(molecule
  (phenyl :ortho (O)))
#+end_src
