#+begin_quote
This file exercises the SVG exporter and the Org Babel integration.

*Prerequisites*

- Emacs 29.1+ with SVG image support.
- `chem-mode` from the `svg` branch on the load path.
- `emacs-indigo` 0.13.0 or newer, with its dynamic module installed.
- Org Babel integration loaded in your config:
  #+begin_example emacs-lisp
  (after! org
    (require 'chem-babel)
    (add-to-list 'org-babel-load-languages '(chem-smiles . t))
    (add-to-list 'org-babel-load-languages '(chem-mol . t)))
  #+end_example

*How to use this file*

1. Save this file somewhere you can write (for example `~/org/chem-playground.org`).
2. Put point in a source block and press =C-c C-c= to execute it.
3. Toggle inline images with =C-c C-x C-v= if they do not appear automatically.
4. Re-run everything with =M-x chem-org-regenerate-buffer=.
5. Remove orphaned images with =M-x chem-org-clean-cache=.

SVG blocks require =:results file=.  The SVG renderer and =:exports results=
are the defaults.  Chemfig blocks require =:results value= or =:results raw=.

Generated images are written to =.chem-cache/ next to this file and linked
relative to it.  Add =.chem-cache/= to your project's ignore rules if needed.
#+end_quote

* Setup check

Run this block once.  It should report =t= for =chem-babel= and =chem-smiles=.

#+begin_src emacs-lisp :results value replace
(list :chem-babel (featurep 'chem-babel)
      :chem-smiles (fboundp 'org-babel-execute:chem-smiles)
      :chem-mol (fboundp 'org-babel-execute:chem-mol)
      :indigo-version (and (fboundp 'indigo-version)
                           (ignore-errors (indigo-version))))
#+end_src

Notes:

- CIP labels render only for =:R=, =:S=, =:r=, and =:s=.
- =:E= and =:Z= bond CIP descriptors are not rendered.
- The EITHER format (=eN=) is supported by the formatter, but Indigo's SMILES
  reader reports the fixture above as ABS.  The renderer tests cover =eN=.
- Labels are placed above-right of the stereocenter in v1; collision avoidance
  is deferred.

* One-off images and cache commands

- =M-x chem-insert-image= (=C-c m i= when =chem-mode= is active) writes a
  one-off image link using =chem-image-directory=.  It is not the reproducible
  Org Babel path.
- =M-x chem-org-regenerate-buffer= re-executes every =chem-smiles= and
  =chem-mol= block in the buffer.
- =M-x chem-org-clean-cache= deletes generated SVGs that are not linked from
  the current buffer.
- Export this file to HTML with =C-c C-e h h=.  With the default
  =:exports results=, the SVG links are included as images.
- For LaTeX, use the chemfig renderer with =:results value :wrap latex=.

Known v1 limits:

- SVG blocks require an explicit =:results file=.
- No E/Z labels, allene aR/aS labels, or isotope labels.
- Text metrics are approximate; stereo labels do not avoid collisions yet.
- SVG IDs are fixed; one rendered SVG per image file is the intended use.
- Org Babel sessions and asynchronous execution are not supported.
