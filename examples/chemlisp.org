#+title: CheMLisp tour (experimental)
#+author: Giovanni Crisalfi
#+STARTUP: inlineimages

A short tour of the experimental CheMLisp DSL.  CheMLisp uses Indigo for
automatic 2D layout and hydrogen perception; explicit angles below are
overrides that force a particular depiction.

#+begin_src elisp :exports none
(require 'chem-babel)
#+end_src

* Ethanol

#+begin_src chemlisp :results file
(molecule
  (C
    (C
      (O))))
#+end_src

* Acetic acid with forced angles

#+begin_src chemlisp :results file
(molecule
  (C
    (C :angle 30
      (=O :angle 60)
      (O :angle -60))))
#+end_src

* Benzene

#+begin_src chemlisp :results file
(molecule
  (c
    (c
      (c
        (c
          (c
            (c
              (-> ^5))))))))
#+end_src

* Naphthalene

Fused rings use one tree: the second ring branches from the shared atom and
closes back to the first.

#+begin_src chemlisp :results file
(molecule
  (c
    (c
      (c (c (c (c (-> ^5)))))
      (c (c (c (c (-> ^5))))))))
#+end_src

* A phenyl template

#+begin_src chemlisp :results file
(chem-def phenyl (ortho meta para)
  (c
    (c
      (c
        (c
          (c
            (c
              (-> ^5)))
          (para))
        (meta))
      (ortho))))

(molecule
  (phenyl :para (O)))
#+end_src

* Local values

#+begin_src chemlisp :results file
(chem-let ((hydroxyl (O))
           (methyl   (C)))
  (molecule
    (C
      (C (hydroxyl))
      (methyl))))
#+end_src

* Chemfig output

#+begin_src chemlisp :renderer chemfig :results value
(chem-def hydroxyl () (O))
(molecule (C (C (hydroxyl))))
#+end_src
