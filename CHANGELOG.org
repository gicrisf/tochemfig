#+title: Changelog
#+author: Giovanni Crisalfi

All notable changes to =chem-mode= are documented in this file.

* 0.4.0 (unreleased)

IR-first refactor.  The package is now =chem-mode=; chemfig is an exporter.

** Added
- =chem-ir.el=: flat graph plus tree view, explicit geometry, and per-node
  drawing attributes.
- =chem-export.el= and =chem-options.el=: exporter and option registries.
- =chem-exp-chemfig.el= and =chem-exp-chemfig-mappings.el=: the chemfig
  exporter, including all chemfig presentation state.
- =chem-mode.el= and =chem-dispatch.el=: generic commands, minor/global mode,
  and a manually grouped transient with an exporter selector.
- =tools/validate-corpus.el=: corpus output and graph validation helper.

** Changed
- Indigo ingestion now lives in =chem-indigo.el=; the drawing IR contains no
  Indigo handle.
- Common drawing decisions (labels, numbering, bond decoration, ring display)
  are stored in the IR.  Exporters render attributes instead of re-reading
  common options.
- The package entry is =chem-mode.el=.  The old =tochemfig-*= mode, dispatch,
  commands, and variables are removed.

** Migration
=chem-mode= makes a clean break: the old =tochemfig= commands and variables
are not aliased.  See [[file:MIGRATION.org][MIGRATION.org]] for the full mapping and optional
compatibility snippets.

* 0.3.0 (unreleased)

Fully native, dependency-free chemfig generation.

** Added
- A native Elisp port of the =mol2chemfig= chemfig generator, split into
  =tochemfig-mappings.el=, =tochemfig-atom.el=, =tochemfig-bond.el= and
  =tochemfig-molecule.el=.
- A context-aware =tochemfig-mode= (=C-c m= prefix) that generates chemfig
  code from the region or the SMILES string at point, wraps output in
  =\chemfig{...}= in LaTeX and Org buffers, and keeps options buffer-local.
- A =transient= options menu, =tochemfig-dispatch= (=tochemfig-custom=),
  replacing the old completing-read wizard.  It lives in the new
  =tochemfig-transient.el= and is autoloaded by =tochemfig.el=, so it is
  available without manually loading =tochemfig-mode=.
- Transient actions for one-off file input (=F=) and one-off rotation (=A=).
- A parity test suite (about 330 ERT tests) comparing output against golden
  files produced by the reference =mol2chemfigPy3= implementation, plus a
  chemfig syntax validator and mode tests.
- A structural correctness suite: generated chemfig is parsed back into a
  molecular graph and compared with the Indigo input via canonical SMILES
  (=test/tochemfig-chemfig-parser.el=, =test/tochemfig-graph-test.el=),
  independent of the reference golden files.  It covers the SMILES/layout
  path, an expanded MOL corpus (stereo, isotopes, charges, macrocycles, a
  160-atom structure), an option matrix asserting that every non-destructive
  option profile preserves the molecule, and a randomized fuzz smoke test.
- =tools/check-perception.py=, invoked by =tools/gen-goldens.py=, which fails
  loudly when =emacs-indigo= and the reference =epam.indigo= disagree on the
  corpus.  New golden profiles: =legacy-lewis=, and extra =cross=/=entryexit=
  cases.
- A =flake.nix= development shell providing the Python reference toolchain.
- New options: =-aromatic-circles=, =-cross-bond=, =-markers=, =-strict=,
  =-recalculate-coordinates= and legacy Lewis radicals.
- New commands: =tochemfig-aromatic-circles=, =tochemfig-markers= and
  =tochemfig-cross-bond=.
- A global minor mode, =tochemfig-global-mode=, that enables =tochemfig-mode=
  only in the wrapping contexts (opt into every buffer with
  =tochemfig-global-mode-all-buffers=).
- Configurable wrapping contexts (=tochemfig-mode-wrap-modes=, now including
  =markdown-mode=), per-command wrapping and LaTeX source blocks inside Org.
- Option lifecycle commands: =tochemfig-describe-options=,
  =tochemfig-save-options= / =tochemfig-reload-options= (global defaults) and
  =tochemfig-reset-options= (buffer or, with a prefix, global).
- SMILES registered as a =thing= at point (=forward-tochemfig-smiles=,
  =bounds-of-thing-at-point=) with a prose-rejecting, customizable
  =tochemfig-smiles-looking-predicate=.
- An optional menu-bar entry shown while =tochemfig-mode= is active.

** Changed
- =tochemfig= now requires Emacs 29.1 (was 28.1).
- Generation failures in =tochemfig-mode= now surface as =user-error= instead
  of a raw Indigo error; blank SMILES input signals a =user-error= rather than
  an internal error.
- The =tochemfig-default-*= options are localized lazily (on first edit)
  instead of eagerly on enable, so global default changes keep reaching
  enabled-but-unedited buffers; wrapping is decided per command rather than at
  enable time.  The transient Generate/Copy actions are now safe when the
  invoking buffer has been killed.
- Region-replacing commands deactivate the mark, so Evil leaves visual state
  after generating; the =*tochemfig options*= buffer uses Emacs state under
  Evil (so =q= quits it).  Documented Evil/Doom usage, including a leader
  =map!= snippet (=SPC C= prefix), without adding an Evil dependency.
- Reduced the =tochemfig-mode= keymap (clean break) to =C-c m g= generate,
  =o= options menu, =c= copy and =d= describe options.  The mode-aware
  toggles/rotation (=C-c m t/w/r=) and the =C-c m f= file shortcut are gone;
  those workflows now live in the transient menu.  New transient actions:
  =F= (generate from file) and =A= (rotate once).
- =tochemfig= now depends on =emacs-indigo= instead of a Python
  =mol2chemfig= installation.
- Ported the full rendering algorithm: trunk marking, fragment connection,
  ring annotation, fancy double/triple bonds, relative angles,
  atom/charge/hydrogen placement and terse/verbose output formatting.

** Fixed
- Byte-compilation no longer depends on emacs-indigo's dynamic module loading at
  build time: the =indigo-with-*= resource macros are now required explicitly at
  compile time (=tochemfig.el=, =tochemfig-molecule.el=).  Previously, building
  where the module could not load (e.g. some =doom sync= environments) produced a
  =tochemfig.elc= with unexpanded macros that failed at runtime with
  =void-function mol=.  The =indigo= dependency is also relaxed to =0.10.1=, and
  a clear error is signalled if the macros are unavailable.
- =tools/check-module-free-compile.sh= guards against the above regression by
  byte-compiling tochemfig with a stubbed =indigo= (module never loaded) and
  asserting the macros were expanded.

** Removed
- The Python =mol2chemfig= / =mol2chemfigPy3= command interface and the
  =tochemfig-default-command= option.
- PubChem input, which required network access.
- The one-shot command surface that duplicated the transient with a fixed
  option and always prompted for SMILES: =tochemfig-default=,
  =tochemfig-input-file=, =tochemfig-input-direct=,
  =tochemfig-input-direct-output-file=, =tochemfig-input-file-output-file=,
  =tochemfig-terse=, =tochemfig-verbose=, =tochemfig-indent=,
  =tochemfig-rotate=, =tochemfig-show-carbons=, =tochemfig-show-methyls=,
  =tochemfig-add-hydrogens=, =tochemfig-delete-hydrogens=,
  =tochemfig-fancy-bonds=, =tochemfig-vanilla-bonds=,
  =tochemfig-aromatic-circles=, =tochemfig-no-aromatic-circles=,
  =tochemfig-show-atom-numbers=, =tochemfig-hide-atom-numbers=,
  =tochemfig-bond-scale=, =tochemfig-bond-normalize=, =tochemfig-markers=,
  =tochemfig-cross-bond=, =tochemfig-wrap-chemfig=, =tochemfig-wrap-submol=,
  =tochemfig-unwrap= and =tochemfig-partial-submol=.  Use
  =tochemfig-dispatch=, =tochemfig= and =tochemfig-copy= instead.
- The now-redundant mode commands =tochemfig-convert-region=,
  =tochemfig-mode-toggle-terse=, =tochemfig-mode-toggle-wrap-chemfig= and
  =tochemfig-mode-rotate=.

* 0.2.0
- First attempt at a native Elisp generator (=tochemfig-core.el=).
- Autoloaded minor mode.

* 0.1.5
- Python =mol2chemfig= interface: generate chemfig code from SMILES and MOL
  files by calling an external =mol2chemfig= installation.
- Interactive wizard and single-parameter override commands.
